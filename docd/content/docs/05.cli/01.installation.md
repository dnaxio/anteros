---
title: Installation
description: Install the Anteros CLI — the `anteros` framework binary and the `ros` deployment binary.
navigation:
  icon: lucide:download
---

```bash
bun i @anteros/cli@latest -g
```

This installs the `anteros` binary on your `$PATH`. Nothing else to set up.

If you prefer not to install anything globally, every command also runs through `bunx`:

```bash
bunx @anteros/cli create server my-api
bunx @anteros/cli doctor
```

## Binaries

| Binary    | Scope              | How to run                                              |
| --------- | ------------------ | ------------------------------------------------------- |
| `anteros` | Framework (dev)    | `anteros create`, `anteros dev`, `anteros doctor`       |
| `ros`     | Deployment (CI-CD) | `anteros ros <command>` (`ros deploy`, `ros status`, …) |

## Verify

```bash
anteros --version
anteros ros --version
```

## Requirements

- **Bun** ≥ 1.3
- **MongoDB** — local (`mongodb://localhost:27017`) or hosted (for the framework)
- **SSH** access to remote servers (for `ros`)
- **Docker** ≥ 24 (on remote servers, for container pods)
