title: Query Predicates
description: Filter and match documents using query predicates.
icon: Filter
---

Query predicates are used in the `$match` pipeline stage (passed to `rest.find()`, `rest.aggregate()`, and other methods) to filter documents before further processing. They use MongoDB's query syntax.

---

## Comparison Operators

| Operator | Description |
|----------|-------------|
| `$eq` | Equal to |
| `$ne` | Not equal to |
| `$gt` | Strictly greater than |
| `$gte` | Greater than or equal |
| `$lt` | Strictly less than |
| `$lte` | Less than or equal |
| `$in` | Value is in the given array |
| `$nin` | Value is NOT in the given array |

```typescript
import { useRest } from '@anteros/core';

const rest = new useRest({ tenant_id: 'v1' });

// Products between 10€ and 100€, published, in stock
const products = await rest.find('products', {
  $match: {
    price:  { $gte: 10, $lte: 100 },
    status: { $in: ['published', 'featured'] },
    stock:  { $gt: 0 }
  }
});
```

```typescript
// Users except admins and moderators
const regularUsers = await rest.find('users', {
  $match: {
    role: { $nin: ['admin', 'moderator'] }
  }
});
```

## Logical Operators

| Operator | Description |
|----------|-------------|
| `$and` | All conditions must match |
| `$or` | At least one condition must match |
| `$nor` | None of the conditions must match |
| `$not` | Inverts the condition that follows |

```typescript
// Admins OR users with the manage_users permission
const privileged = await rest.find('users', {
  $match: {
    $or: [
      { role: 'admin' },
      { permissions: { $in: ['manage_users'] } }
    ],
    status: { $ne: 'banned' }
  }
});
```

```typescript
// Users of legal age AND either premium or verified
const eligible = await rest.find('users', {
  $match: {
    $and: [
      { age: { $gte: 18 } },
      {
        $or: [
          { plan: 'premium' },
          { verified: true }
        ]
      }
    ]
  }
});
```

## Element Operators

| Operator | Description |
|----------|-------------|
| `$exists` | Field exists (or does not exist) |
| `$type` | Field matches the given BSON type |

```typescript
// Users with a phone number set
const withPhone = await rest.find('users', {
  $match: { phone: { $exists: true } }
});

// Documents whose discount field is a number
const numericDiscount = await rest.find('products', {
  $match: { discount: { $type: ['int', 'double', 'decimal'] } }
});
```

---

## Array Operators

| Operator | Description |
|----------|-------------|
| `$all` | Array field contains ALL specified values |
| `$elemMatch` | At least one array element matches all conditions |
| `$size` | Array field has exactly N elements |

```typescript
// Users having AT LEAST the read AND write permissions
const withRw = await rest.find('users', {
  $match: { permissions: { $all: ['read', 'write'] } }
});

// Orders containing at least one item over 100€
const bigOrders = await rest.find('orders', {
  $match: {
    items: { $elemMatch: { price: { $gt: 100 } } }
  }
});

// Users with exactly 3 roles
const threeRoles = await rest.find('users', {
  $match: { roles: { $size: 3 } }
});
```

## Evaluation Operators

| Operator | Description |
|----------|-------------|
| `$regex` | Pattern matching (regular expression) |
| `$expr` | Use aggregation expressions inside a query |
| `$mod` | Modulo operation |
| `$text` | Full-text search on a text index |

```typescript
// All emails at @gmail.com (case-insensitive)
const gmailUsers = await rest.find('users', {
  $match: {
    email: { $regex: /@gmail\.com$/, $options: 'i' }
  }
});
```

```typescript
// Users whose spending ≥ their credit limit
const overLimit = await rest.find('users', {
  $match: {
    $expr: { $gte: ['$spent', '$creditLimit'] }
  }
});
```

```typescript
// Documents where quantity is a multiple of 4
const multiples = await rest.find('items', {
  $match: { quantity: { $mod: [4, 0] } }
});
```

## Geospatial Operators

| Operator | Description |
|----------|-------------|
| `$geoWithin` | Geometry inside a defined region |
| `$geoIntersects` | Geometry intersects a region |
| `$near` | Points near a geographic point |
| `$nearSphere` | Points near a point (spherical geometry) |

```typescript
// Shops within a 5 km radius around Paris (2.35, 48.85)
const nearbyShops = await rest.find('shops', {
  $match: {
    location: {
      $near: {
        $geometry: { type: 'Point', coordinates: [2.35, 48.85] },
        $maxDistance: 5000
      }
    }
  }
});
```

## Bitwise Operators

| Operator | Description |
|----------|-------------|
| `$bitsAllSet` | All specified bits are set |
| `$bitsAllClear` | All specified bits are clear |
| `$bitsAnySet` | At least one of the specified bits is set |
| `$bitsAnyClear` | At least one of the specified bits is clear |

```typescript
// Documents with bit 3 (value 8) set in the flags field
const withFlag = await rest.find('configs', {
  $match: { flags: { $bitsAllSet: 8 } }
});
```
