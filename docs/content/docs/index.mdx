## All in One Backend Framework

A robust backend server built on **Bun** as the JavaScript runtime and **MongoDB** as the database. Includes multi-tenant architecture, unified REST API, JWT authentication, hooks, file uploads, workflow engine, and more.

## Why Anteros?

- **Blazing Fast** — Powered by Bun, one of the fastest JavaScript runtimes available.
- **MongoDB** — Full database integration with automatic schema validation, indexing, and aggregation pipeline support.
- **Multi-Tenant** — Isolate data between tenants with isolated database connections and per-tenant code folders.
- **File Upload** — Built-in file upload system with disk/S3 storage, image transformations via Bun.Image, and multi-destination replication.
- **Workflows** — Sequential step execution with progress tracking, compensation (Saga pattern), versioning, and resume on failure.
- **Security** — JWT authentication, configurable access control, rate limiting, IP restriction, and tenant middlewares.
- **Hooks** — Execute logic before and after database operations with lifecycle hooks.
- **Unified REST API** — Single endpoint pattern for all CRUD, custom actions, services, uploads, and file serving.
- **Audit Trail** — Automatic activity logging for every database operation with trace correlation and collection-type tracking.

## Backend Framework

Built for teams that want one cohesive stack — runtime, HTTP API, data layer, file management, workflow orchestration, and tenant isolation — without stitching together disparate tooling.
