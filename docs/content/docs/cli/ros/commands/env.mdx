---
title: ros env
description: Show the resolved environment variables.
icon: KeyRound
---

```bash
ros env [env] [pod]
```

Dumps the configuration values as they are resolved by `ros`, after `${VAR}`
expansion and default substitution.

## Examples

```bash
# Project-wide config
ros env

# Environment-specific values
ros env production

# Resolved env vars for a pod
ros env --pod api

# Combine
ros env production api
```

## Output

```
Project ───────────────────────────────────────────────────
Name      dnx
Version   1
Tag       v1.0.2
Strategy  rolling
```

For a pod, the env vars are listed as a key-value table with all
substitutions applied (e.g. `${API_PORT:-3001}` is resolved to `3001` if
`API_PORT` is unset).
