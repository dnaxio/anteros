The Anteros CLI is shipped as a single npm package, `@anteros/cli`, that exposes two binaries:

| Binary | Scope                | Purpose                                                  |
|--------|----------------------|----------------------------------------------------------|
| `ant`  | Framework            | Project scaffolding, dev workflow, code generation       |
| `ros`  | Deployment / CI-CD   | Multi-server deployment over SSH                         |

Both share the same package, configuration format, and plugin system.

## Installation

```bash
bun i @anteros/cli@latest -g
```

This installs both `ant` and `ros` on your `$PATH`.

## Choosing the right binary

- **Writing code?** → use [`ant`](/docs/cli/ant)
- **Shipping / operating code?** → use [`ros`](/docs/cli/ros)
