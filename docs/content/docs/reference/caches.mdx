The `cache` object provides native caching utilities backed by **Bun**: an in-memory **L1 layer** on every driver, plus an optional **L2 layer** (filesystem or **`Bun.Redis`**) for persistence and distribution. Zero external cache dependencies.

## Available Drivers

| Driver       | Description                                    |
| ------------ | ---------------------------------------------- |
| `useMemoryCache`    | In-memory caching (fastest, no persistence)    |
| `useFilesystemCache` | Memory L1 + file-based L2 with configurable directory |
| `useRedisCache`    | Memory L1 + Redis L2 (native `Bun.Redis`) for distributed setups |

## Memory Cache

In-memory cache with L1 layer. Data is lost when the process exits.

```typescript
import { cache } from "@anteros/core";

const c = cache.useMemoryCache();
```

## Filesystem Cache

File-based cache with a configurable directory. Uses L1 (memory) + L2 (file) layers.

```typescript
import { cache } from "@anteros/core";

const c = cache.useFilesystemCache({
  directory: "./.cache",
  pruneInterval: "1h",
});
```

| Option           | Type     | Default  | Description                                      |
| ---------------- | -------- | -------- | ------------------------------------------------ |
| `directory`      | `string` | —        | Directory path for cache files                   |
| `pruneInterval`  | `string` | `"1h"`   | Interval for pruning expired entries              |

## Redis Cache

Redis-backed cache for distributed setups (e.g. cluster mode with multiple workers). Uses L1 (memory) + L2 (native `Bun.Redis`) layers.

```typescript
import { cache } from "@anteros/core";

// By host / port / password
const c = cache.useRedisCache({
  connection: {
    host: "localhost",
    port: 6379,
    password: "",
  },
  pruneInterval: "1h",
});

// Or by URL (takes precedence)
const c2 = cache.useRedisCache({
  url: "redis://user:pass@localhost:6379/0",
});
```

| Option           | Type     | Description                                      |
| ---------------- | -------- | ------------------------------------------------ |
| `connection.url`      | `string` | Full Redis URL (overrides host/port/password) |
| `connection.host`     | `string` | Redis server host                         |
| `connection.port`     | `number` | Redis server port                         |
| `connection.password` | `string` | Redis server password                     |
| `connection.db`       | `number` | Redis database number                     |
| `pruneInterval`       | `string` | Interval for pruning expired entries       |

## Usage

All methods accept an options object and support human-readable TTLs (e.g. `"5m"`, `"2.5h"`) or milliseconds.

```typescript
const c = cache.useMemoryCache();

// Set a value
await c.set({ key: "products", value: { id: 1 }, ttl: "5m" });

// Set a value that never expires
await c.setForever({ key: "config", value: { theme: "dark" } });

// Get a value
const value = await c.get({ key: "products" });

// Get or set via factory (recommended)
const products = await c.getOrSet({
  key: "products",
  factory: async () => {
    return await rest.find("products");
  },
  ttl: "10m",
  grace: "1m",
});
```

The **`grace`** option keeps the previous value after expiration and serves it on the next `getOrSet` while refreshing the cache in the background (stale-while-revalidate).

```typescript
// Get or set with no expiration
const config = await c.getOrSetForever({
  key: "config",
  factory: () => loadConfig(),
});

// Check existence
const exists = await c.has({ key: "products" });
const missing = await c.missing({ key: "products" });

// Get and delete
const item = await c.pull({ key: "products" });

// Delete
await c.delete({ key: "products" });

// Mark as expired now (keeps value for the grace period)
await c.expire({ key: "products" });

// Delete multiple
await c.deleteMany({ keys: ["products", "users"] });

// Clear all entries
await c.clear();

// Prune expired entries (useful for file/database drivers)
await c.prune();

// Release the Redis connection and stop the prune timer
c.disconnect();
```

## Namespaces

Group keys for bulk invalidation:

```typescript
const users = c.namespace("users");
await users.set({ key: "1", value: { name: "John" }, ttl: "5m" });
await users.set({ key: "2", value: { name: "Jane" } });
await users.clear(); // clears only this namespace
```

## Notes

- The L1 memory layer makes reads fast on every driver; the L2 layer (`Bun.Redis` / filesystem) provides persistence and sharing between processes.
- Redis keys are stored with a Redis TTL so expired entries are reclaimed by Redis itself.
- Requires **Bun ≥ 1.2.23** for `Bun.Redis`.
