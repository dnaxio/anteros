## Requirements

- **Bun** 1.0+
- **MongoDB** 6.0+

## Install

```bash
bun init -y
bun install @anteros/core@latest
```

For a guided first project (folders, model, boot script, sample `curl` calls), use **[Quick Start](/docs/getting-started/quick-start)**.
